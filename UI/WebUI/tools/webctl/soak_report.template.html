How this run was set up

Sampled once a minute by soak6h.mjs, which holds the machine's host link open for the whole run — the peripheral channel belongs to the browser that opened it, so the plate stops if that browser goes away. A flat heap on a stopped machine is the most convincing wrong answer this bench can produce, which is why the panel text and the board state are sampled alongside the memory and shown here together.

Cumulative counters (cal_fail, cal_lost, nm_orphan) carry values from before this run; the cards show the change since minute zero, which is the only part this run is responsible for.
