## 1. The one thing that is still broken

**The core crashes while running the fake camera, and the frequency tracks image
brightness.** Two crash signatures were found and both are fixed — but neither
fix explains the correlation, so this is open.

- `std::length_error: vector` after `ImgInspection w:6 h:6` — `CalcROI` composed
  a 6×6 window at origin (−6,−6) from an empty `img_load`. Fixed (`d9cd59b4`).
- `cvtColor: !_src.empty()` — both `ExtractFrame` callers ignored the return
  status, so a refused frame was converted anyway. Fixed (`96b69762`).

**What is not explained:** with the exposure simulation still crushing frames to
1% brightness, images loaded fine. After that was turned off (normal brightness)
it began crashing often. Neither guard above has anything to do with brightness.

**The 30-second test that decides where to look next:** open the fake-camera gear
panel, enable `expo_sim_en` and set `expo_us` 50 — that reproduces the old dark
frames. If the crashes stop, the fault is downstream of brightness (binarization
→ labeling: brighter frame, far more foreground, far more labels), not in the
camera layer. If they continue, there is a third unguarded path.

Also worth a look on its own: `data/jog_center.png` returns `imread ret:-1`. The
extension filter cannot catch that — right extension, undecodable content.

## 2. Shipped, verified on hardware

**The machine survives losing its host.** The core sends a 10/s idle ping (only
when the link is quiet — the saving is not bandwidth, it is staying out of
`perif_tx_lock`, shared with the report path). `host_timeout_ms` (1000, set by
the core, not by device NVS) turns its absence into `HOST_LINK_TIMEOUT`, which
stops the plate and writes the sorting counters to their own NVS key. Restored on
boot. This closes **B4** in `DEV_COMPLETE_CHECKLIST.md`.

Why it exists: **opening the serial port reboots the board.** DTR/RTS are wired
to EN. A browser refresh did it (measured: uptime 611s → 1s) and is now fixed by
CONNECT reusing a live channel. A core restart still does it and **cannot be
fixed from userspace** — suppressing DTR/RTS after `open()` was implemented and
measured to change nothing, because the pulse is inside `open()`. Reverted; do
not spend an afternoon on it again. See `A8` in the checklist.

The counter save hangs off **state entry** (entering ERROR, entering IDLE), never
off the comm timeout itself. Losing the host is a condition, not an event; outside
the state machine it needs a latch, and the latch's failure mode is writing flash
until the operator comes back tomorrow. It also skips the write when nothing was
counted, so the write rate follows counting rather than faulting.

**Verified:** killed the core mid-run at SEL1 108 / SEL3 423 / NA 234; the device
stopped, saved in 55 ms, the relaunch rebooted it, and it came back with
`cnt_restored: true` and the counts intact.

## 3. Shipped, NOT verified on hardware

Everything from here was done after the rig was unplugged. It builds and the
reasoning is in the commits, but nothing below has run on a machine.

- **`InspectionROI`** replaces the stored `ROI`. Any "show me the full frame"
  gesture used to overwrite the machine's persisted crop — the machine was found
  at `[0,0,99999,99999]` with the real value unrecoverable from any log. Only the
  Inspection UI's completed picker writes it now, under its own key. Verified
  only in the sense that the operator re-drew it and the file came back correct.
- **CalibUI opens the sensor fully.** Calibration measures optics, not product;
  through a crop it is valid only inside that crop and silently wrong afterwards.
- **`work_region` on `II`.** The def editor's CHECK was enforcing the production
  station filter, dropping every object before measurement and returning an empty
  report — which reads as "the snap is broken". The caller now says whether it is
  authoring or judging.
- **`region_dropped`** in the sig360 report, so an empty object list can say
  whether the region is why.
- **The shape template path is stamped on the FI/CI wire copy.** It was missing
  only on the path that goes to production, so shape-based matching silently
  downgraded to sig360. Stamp it on a COPY: `_ref_image_path` has one underscore
  and the def hash only strips double-underscore keys, so putting it on the
  shared object breaks `featureSet_sha1` and the next load is refused.
- **New `search_point`s are born caliper** with `min_strength 60`,
  `include_range 0.01`. Set at the construction site, NOT as the schema default —
  the core reads a missing `locating` as contour, so moving the default would
  make the editor show caliper for a def that runs as contour and then write that
  change in on the next save.
- **物件偵測 (obj_detect) can no longer be created.** Drawing/editing/core support
  stay: a field def may still carry regions that fold into the verdict, and a
  check you cannot see is worse than one you can see and remove.
- **Fake camera:** exposure simulation is off by default and owned by the fake
  camera's own knobs (gear panel), not by the shared camera settings. The folder
  listing is filtered to decodable extensions.

## 4. Instruments that will lie to you

Every one of these produced a wrong conclusion during the session.

- **`cnt_nvs_lat_ms` cannot tell a fresh save from a stale record.** It measures
  `selHoldMs()`, so every save reports the same number (55 here). Use
  `cnt_nvs_seq`. I concluded "it did not save" from it once, wrongly.
- **`get_running_stat` overflows at ~2900/3072** and then returns
  `stat_doc_overflow` — losing the whole status, not just the new fields. New
  fields need their own command (`get_backup_stat`, `get_spikes`).
- **The perif console forwards raw text to the device.** A stray `?` latched the
  link; `clear_error` did not clear it and only `{"type":"RESET"}` did. The
  console now refuses non-JSON, and `clear_error` now clears both latches.
- **The WebUI is on 8081.** Chrome rendering an error page looks exactly like
  "the fix worked" — two rounds of measurements were void because of this.
- **Core logging is RAM-ring only, persist off.** "Not in the log" means nothing.
