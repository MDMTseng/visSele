## 1. State: what is now true that wasn't

**Core — the measuring instrument no longer lies (Tier 1, all closed).**
value_A==value_B can't NaN a part into PASS; a caliper band off-frame measures
instead of inventing (the old behaviour was rms 1.99mm presented as a
measurement); degenerate fits can't return the def's nominal as "measured";
malformed calib files are refused instead of green-ACKed; refused camera
setters land in `camera_info.setup_failed` (which immediately caught the fake
camera silently ignoring blacklevel/gamma); `station.skip_inspection` /
`ignore_calib` are on every frame.

**Core — a dead sorter link is visible (was: UI green, nothing sorting).**
`perif_pairing.link` carries tx_fail / tx_fail_consec / dropped_no_channel /
suspect; a suspect link declines CONNECT reuse and reopens; Windows
`WriteFile`'s discarded BOOL (deployed platform!) is checked. One reading
rule: **any of these counters moving while parts run = the machine is not
sorting.** The WebUI now draws them (PerifStatus).

**Core — writes are durable.** SV (how the WebUI saves defs and
machine_setting.json) goes through tmp+fsync+rename; a full disk keeps the old
file. The snapshot-dir fallback no longer `exit(-100)`s the whole core.

**Core — WS layer.** Image stream defaults to JPEG 85 (was raw RGBA,
19.7MB/frame, 187x). One stalled browser wedges everyone for ≤ ~5s
(SO_SNDTIMEO + shutdown-on-failure) instead of forever; the sorter itself was
proven to keep running through a wedge.

**WebUI — peripheral layer is a module (`src/perif/`).** Perif_API_Base + 4
device classes out of script.jsx (-1100 lines), link state OUT of Redux
(module store + `usePerifLink`/`usePerifConn`; a 3s PING notifies that
device's subscribers, not every mapStateToProps in the app). Reconnect has
backoff; SUSPECT exists and is drawn. The ConnInfo reducer's perif cases are
gone.

**WebUI — the editor def is safe from inspection mode.** Tag-limit overrides
restore on exit (by value per overridden id — the first, identity-gated
version silently never ran; the E2E's console trace caught it). The station
panel read-merge-writes only its two keys into machine_setting.json, so two
browsers can't silently revert each other. The margin editor works on a clone
(the dirty check no longer says "no changes" while grading reads edits).

**The "1006 disconnect" is solved and was never the network.** queryCam saw
the idle fake camera (`cam_status != 0`), declared REMOTE_SYSTEM_NOT_READY,
and ALLOW_SOFT_CAM=false blocked reconnection → a ~5s SPLASH↔MAIN loop
forever. Dev builds now allow the soft cam; production unchanged. If SPLASH
cycling returns: check `cam_status` first (caminfo.mjs), not the network.

**Test infrastructure that didn't exist:** the `--insp` full-precision
leaf-diff gate (bit-identical golden after every measurement change, run ~12
times these two days), ~10 live webctl probes, and the WebUI flow suite at
9/9 including **inspCycle** — the operator's main road (recipe → real menu
entry → tag limits applied → exit → restored), with every choreography trap
it took to build written into its comments.

## 2. What will mislead you

- **The 10221 golden reads `machine_setting.json`'s `inspection_region`** and
  silently drops every label (0 objects, no error) if a uInsp station region
  is left over. Bitten twice. Remove/restore around the run.
- **inspection stream perf on this bench:** renderer CPU is ~24% streaming.
  The frozen-view **idle floor turned out to be one CSS animation, not polls**
  (see TODO 1, resolved) — the JS layer at idle is genuinely quiet: 0 rAF,
  0 draws, 0 DOM mutations, ~2 timer fires/s. The canvas double-draw is fixed
  (draw_INSP 10.3 → 5.1/s = one per frame) but that bought correctness, not
  CPU.
- The FI play button inspects the **recipe selected at MAIN**, not whatever an
  editor session holds. LD result acts are dropped outside the editor.
- Synthetic DOM events no-op on per-shape PropertySheets and antd controls —
  drive the UI only with webctld's real Playwright endpoints.

## 3. TODO, ranked

1. ~~**WebUI idle-floor investigation**~~ **RESOLVED 08-16.** The suspects
   (queryCam poll, SLID poll, rAF) were all innocent — instrumentation showed
   0 rAF / 0 draws / 0 mutations at idle. The floor was
   `DISCONNECT_Blink_ANIMATION`: a `background-color` CSS animation runs on
   the main thread and forces style+paint every vsync, so one
   disconnected-device button cost ~3.6 CPU points forever (5.2% → 1.6%
   paused; `step-end` timing does NOT help — Chromium ticks main-thread
   animations per frame regardless). Fix: blink via `opacity` (composited)
   over a static background — measured 5.2% → ~2.2% with the blink still
   running. Moral for future UI work: **never animate paint properties on
   long-lived status indicators; animate opacity/transform only.**
2. **Camera state: poll → push, and stop treating camera-idle as
   system-down** — queryCam's `cam_status != 0 → WS_ERROR → SPLASH` resets
   the whole app session over a camera that merely stopped acquiring. Core
   should push camera state (the station block already goes out per frame;
   add `cam_status`), UI should show "camera idle", not reboot itself.
3. **Core WS layer locks (backlog 2.1 / 2.6)** — the shared-thread send path
   races (`sendBuf` realloc under a sender, fd reuse after close) and
   `conn_peer`'s contract rests on MT_LOCK, which is a no-op. This is the
   largest remaining crash surface. Bounded by the 5s send timeout now, not
   fixed.
4. **loadedDefFile resurrection (Tier 5, deferred)** — needs a save-flow
   conflict check: LD the on-disk def, compare featureSet_sha1 against the
   load-time hash, confirm-dialog on mismatch. A UX decision, then ~a day.
5. **Perif phase D (optional polish)** — device-API batching over PD (a
   resync is N serial round-trips at 230400 baud), and GS `perif_pairing` /
   `camera_info` as push-on-change stream items to retire the remaining
   client polls.
6. **BACPAC/MachineContext refactor P0** — plan is written and synced
   ([BACPAC_MACHINECONTEXT_REFACTOR.md](BACPAC_MACHINECONTEXT_REFACTOR.md)),
   P3 mostly landed already, phases are gated on the `--insp` golden. Start
   whenever a quiet stretch exists.
7. **Deliberately parked** (decisions, not patches): 4090 binds INADDR_ANY
   with no Origin check; contourConcatLastTo's single-section self-merge;
   ReadText's short-read check (MinGW text-mode risk); backlog 1.9's
   positional-train placeholder (protocol change).
